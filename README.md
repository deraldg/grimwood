# Grimwood Family Portal

This repository holds the root public pages for `grimwood.family`.

The live hosting account also contains older folders and project archives. Those
folders are intentionally treated as preserved material until reviewed. The new
root portal links to useful areas without deleting or rewriting the legacy
content.

## Branch

The current GitHub branch is `master`. Some tools default to `main`; use
`master` unless the repository is intentionally migrated.

## Publishing Model

- Source of truth: this repository.
- Hosting target: the cPanel/FTP public root for `grimwood.family`.
- Preserved folders stay in place unless explicitly archived or removed.
- Root files such as `index.html`, `default.html`, and `assets/site.css` may be
  replaced by this repository.
